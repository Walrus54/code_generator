# Лабораторная работа по предмету: «Технологии программирования»
## Тема: «Абстрактная фабрика»
> 4 курс 2 семестр

## 1. Постановка задачи
Расширить генератор программ так, чтобы из единой архитектуры порождать код на
нескольких языках: C++, C#, Java. Сгенерированные программы должны корректно
формироваться и компилироваться средствами соответствующего языка.

Для решения используется паттерн проектирования «Абстрактная фабрика».
